# Security Notes

本项目不处理账号、支付、个人数据或远程代码执行。请不要在 Issue 中提交令牌、私钥、学校服务器地址或其他敏感信息。

This project does not handle accounts, payments, personal data, or remote code execution. Do not post tokens, private keys, school server addresses, or other sensitive information in issues.

若发现依赖供应链或脚本执行风险，请通过私下渠道联系维护者，并提供最小复现信息。

If you discover a dependency-supply-chain or script-execution risk, contact the maintainer privately and provide minimal reproduction information.
