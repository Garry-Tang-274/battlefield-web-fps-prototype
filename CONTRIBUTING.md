# Contributing Guide

提交 Issue 时，请同时提供复现步骤、预期行为、实际行为、浏览器版本、操作系统和控制台错误。

When filing an issue, include reproduction steps, expected behavior, actual behavior, browser version, operating system, and console errors.

Pull Request 应聚焦单一问题，避免同时提交无关格式化和功能修改，并保持新增用户可见文本为严格对应的中英双语。

Pull requests should focus on one issue, avoid mixing unrelated formatting and functional changes, and keep all new user-facing text in strictly corresponding Chinese and English.

提交前至少运行 `node --check src/game.js` 和 `python -m py_compile scripts/start_server.py`。

Before submitting, run at least `node --check src/game.js` and `python -m py_compile scripts/start_server.py`.
